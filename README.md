# YARA JAMAL — Birthday Surprise Website 🎂💜

A premium, emotional, interactive birthday website for Yara Jamal.

## Setup

1. Place a birthday cake image at `images/birthday-cake.png`
2. Optionally place background music at `audio/birthday.mp3`
3. Open `index.html` in a browser

## Deploy to Vercel

```bash
npx vercel --prod
```

## Features

- Cinematic opening screen
- Birthday countdown
- Interactive cake with candle wish
- Timeline of shared dates
- Appreciation cards
- Personal letter with scroll reveal
- Secret message reveal
- Confetti effects
- Floating particles
- Cursor trail (desktop)
- Background music toggle
- Fully responsive
- Accessibility support
